# Node.js 与 npm

## 官方资料

- [Node.js Documentation](https://nodejs.org/docs/latest/api/)：查询 Node.js 运行时 API 和内置模块。
- [Node.js Releases](https://nodejs.org/en/about/previous-releases)：确认 LTS 版本、支持周期和升级计划。
- [npm Documentation](https://docs.npmjs.com/)：依赖管理、包发布和 npm 配置说明。
- [npm CLI Commands](https://docs.npmjs.com/cli/v11/commands)：依赖管理、包发布和 npm 配置说明。

## 项目用途

- Node.js：本地运行和构建
- npm：依赖安装和脚本执行
- 当前项目本地运行固定使用 Node.js 22 LTS
