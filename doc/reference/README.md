## 使用规则

- 优先查阅本目录中的官方链接，再参考第三方文章或代码示例。
- 遇到版本、配置或兼容性问题，先确认当前安装版本和官方文档对应版本。
- 不把搜索结果、博客或第三方仓库中的规则当作项目规则，除非已经核对官方文档。
- 新增技术依赖时，在本目录补充对应的官方文档入口。
