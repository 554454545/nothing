# Tailwind CSS

## 官方资料

- [Tailwind CSS Documentation](https://tailwindcss.com/docs)：官方文档入口。
- [Installation](https://tailwindcss.com/docs/installation)：安装 Tailwind 并接入当前构建工具。
- [Theme Configuration](https://tailwindcss.com/docs/theme)：配置颜色、字体、间距和设计 token。
- [Responsive Design](https://tailwindcss.com/docs/responsive-design)：编写不同屏幕尺寸下的响应式样式。

## 项目用途

项目规划使用 Tailwind CSS 编写样式；安装前先确认当前 Tailwind 版本的官方配置方式。
